# Accessibility Guidelines

- Use semantic controls and explicit labels from the shared UI system.
- Ensure every interaction is keyboard reachable with visible focus.
- Give icon-only actions localized accessible names.
- Preserve logical focus order across responsive layout changes.
- Trap and restore focus for modals; implement expected Escape behavior.
- Custom selects must expose listbox/option semantics, selected state, keyboard navigation, and meaningful names.
- Do not communicate status using color alone.
- Respect reduced motion and keep text/controls usable at zoom and with longer translations.
- Keep touch targets comfortably sized and separated.
