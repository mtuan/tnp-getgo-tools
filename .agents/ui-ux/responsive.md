# Responsive Desktop UI Guidelines

- Treat compact windows, standard desktop windows, maximized windows, and portrait-like narrow layouts as intentional states.
- Do not assume a maximized window, hover, keyboard, or precise pointer.
- Prefer shared responsive component behavior before one-off CSS.
- Keep primary navigation, editors, fixed controls, and menus usable without unnecessary visible scrollbars.
- Protect controls from title bars, window edges, internal editor scroll regions, and on-screen keyboards where applicable.
- Ensure translated text does not overlap, hide essential values, or push actions outside the viewport.
- Test at the declared minimum window size as well as the default size.
